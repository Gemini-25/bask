- 각 마일스톤 끝마다 `play/bask.html` 빌드, 커밋, 짧은 보고

### 이번에 정한 것 (2026-10-12)

- 밸런스 목표: **얼마나 잘 키우냐에 따라 다르게.** 대충 키우면 주전급에서 끝나고, 잘 키워야 MVP를 노린다. 지금은 단순한 자동 플레이(팀 훈련·개인 훈련 돌려 쓰기)로도 매년 MVP라서, 잘 키운 것과 대충 키운 것의 차이를 벌리는 쪽으로 맞춘다
- 홈 코트: **응원단 꾸미기 + 우승 배너·영구결번 자동**
- 추가 연출: **전부** (덩크 콘테스트 코트 연출, 우승 세리머니, 드래프트·시상식 무대, 시즌 요약 카드) + **드리블 동작·덩크 동작 더 늘리기**

- 나머지 🟡는 추천안대로 간다 (패널은 백틱·로고 5번 클릭, 치트 쓰면 🔧 표시, 대학 최대 4년 + 얼리 엔트리, 성격 8가지 중 1~2개)

## M9. 개발자 패널 (K9)

예전 결정: 능력치 치트 패널, 확률 오버레이, 시뮬 100배속, 날짜 점프, 이벤트 강제 발동 ✅

### 여는 법 🟡

- 추천: 키보드 `` ` `` (백틱) 또는 머리글의 BASK 로고 5번 클릭. 한 번 열면 브라우저에 기억해서 머리글에 🔧 버튼이 계속 보인다.
- 다른 안: 주소 뒤에 `?dev` (파일을 더블클릭해서 여는 방식이라 불편), 항상 보이는 버튼

### 모양

오른쪽에서 나오는 서랍 패널. 열어 둔 채로 홈·경기 화면을 그대로 쓸 수 있다. 탭 6개:

1. **선수**: 능력치 39개 숫자 입력 (+1/+5/-5, 전부 N으로), 키·체중·잠재력·나이, 피로·컨디션, 부상 치료, 포인트·돈·인기·감독 신뢰·팀 친밀도 넣기, 특수능력 ★ 주기/빼기, 덩크 전부 열기
2. **시간**: N주 자동 진행 (행동은 '자동: 피로 보고 휴식' 또는 '지금 고른 행동 반복', 경기는 결과만, 포인트 자동 투자 켜기/끄기), 이정표로 점프 (다음 경기, 다음 대회, 드래프트, 올스타, 시즌 끝, 재계약, 은퇴 나이), 진행 막대와 멈추기 버튼
3. **이벤트**: 이벤트 전체 목록에서 골라 지금 바로 발생 (조건 무시). 드래프트·올스타·국가대표 소집·해외 제안·재계약·은퇴를 강제로
4. **경기**: 관람 중 확률 오버레이 (슛마다 성공 확률 %, 수비 견제 정도, 슛 종류), 배속 32x·64x·100x 추가, 같은 경기를 다른 시드로 다시, 시드를 넣어서 경기, 선수 머리 위에 체력 숫자
5. **리그**: 아무 선수나 능력치·시즌 기록 보기와 고치기, 라이벌 바꾸기, 리그 순위·시즌 기록 표
6. **세이브**: 지금 상태 JSON 보기·복사, 빠른 스냅샷 3개 (찍기/되돌리기), 업적·명예의 전당 지우기

### 치트 표시 🟡

- 추천: 패널로 값을 바꾸거나 강제 발동하면 그 커리어에 🔧 표시. 업적과 명예의 전당은 그대로 주되 🔧가 붙는다.
- 다른 안: 패널을 쓴 커리어는 업적을 막는다 / 아무 표시 안 함

### 구현 메모

- 확률 오버레이는 엔진이 슛 이벤트에 성공 확률을 같이 적게 한다 (보기만, 결과는 안 바뀜)
- 자동 진행은 지금 있는 `tools/make-save.ts` 규칙을 게임 안으로 옮긴다. 화면이 멈추지 않게 한 주씩 나눠서 돌린다

## M10. 연출

### 10-1. 스틸·블록 때 공 궤적

지금: 스틸하면 공이 수비수 손으로 순간이동한다. 블록은 공이 튀긴 하지만 늘 근처 리바운드처럼 떨어진다.

- 스틸 세 가지
  - 패스 가로채기: 패스 길 중간에서 손을 뻗고, 공이 그 손으로 날아간다
  - 드리블 스틸: 짧게 (0.2초) 공이 수비수 쪽으로 옮겨 간다
  - 쳐내기: 공이 튀어서 루즈볼이 된다. 양 팀이 뛰어가고 다이빙 동작. 공격팀이 다시 잡을 수도 있다
- 블록 세 가지: 관중석으로 날려 버리기 (아웃, 공격권 유지) / 잡아내는 블록 (수비 공) / 튀어서 루즈볼
- 영향: 루즈볼 때문에 스틸·실책 수가 조금 바뀐다. 밸런스 리포트로 다시 맞춘다. 같은 시드라도 예전과 다른 경기가 나온다

### 10-2. 프로 홈 코트·응원 (정함)

- **내 응원단 꾸미기 + 자동 장식**
  - 생활 탭에 '응원' 상점: 등번호 현수막, 응원석 깃발 색, 치어리더, 마스코트, 전광판에 내 얼굴, 내 이름 응원 구호 (관중 말풍선)
  - 자동: 우승하면 그 시즌 배너가 경기장 천장에 걸리고, 영구결번이 되면 내 유니폼이 걸린다. 인기가 높을수록 관중석이 찬다
  - 효과는 작게: 홈 경기에서 인기가 조금 더 오른다
- 다른 안: 구단 경기장을 내 돈으로 직접 꾸미기 (바닥 색, 센터 로고, 조명) / 자동 배너만

### 10-3. BGM

예전 결정은 무료 칩튠 에셋이었다. 하지만 파일 하나로 인터넷 없이 돌아가야 하고 라이선스도 신경 써야 해서, 지금처럼 코드로 작곡한 칩튠을 여러 곡으로 늘린다.

- 타이틀, 고교 홈, 프로 홈, 대회·플레이오프 (긴장), 시상식·우승 (팡파르), 은퇴 (잔잔하게)
- 경기 중엔 음악 대신 관중 소리, 응원 북 리듬, 타임아웃 때 짧은 응원가

### 10-4. 추가 연출 (정함: 전부)

- 드리블 동작 늘리기: 크로스오버, 비하인드 백, 레그 스루, 스핀 무브, 헤지테이션, 스텝백. 돌파·아이솔레이션 때 볼 핸들링에 따라 골라 쓴다 (특수능력 '앵클 브레이커'와 연결)
- 덩크 동작 늘리기: 앨리웁 덩크, 풋백 덩크, 투핸드 리버스, 더블 클러치, 프리스로 라인 덩크 (덩크 콘테스트 전용)
- 덩크 콘테스트를 표 대신 실제 코트에서 도트로 보여주기 (도움닫기 → 덩크 종류별 동작 → 심사위원 점수판)
- 우승 세리머니 장면 (트로피 들기, 그물 자르기, 꽃가루)
- 드래프트·시상식 무대 도트 장면 (단상, 악수, 모자)
- 시즌이 끝나면 내 시즌 요약 카드 (기록, 수상, 최고 경기)

## M11. 밸런스·기록 손질

### 인기

지금은 자동 플레이 기준 프로 2년차에 벌써 100이다.

- 오를수록 덜 오르게 (높을수록 상승량을 줄인다), 고교 동안은 40까지만, 인기가 높을수록 매주 더 빨리 식는다
- 목표: 고교 끝 20~35, 올스타급 3년차 60~70, MVP급 80대. 90은 우승·MVP를 여러 번 했을 때

### 키운 만큼 차이 나게 (정함)

지금 자동 플레이 기준으로 프로 평균 35점, 거의 매년 MVP, 명예의 전당 점수가 기준의 7배다. 단순한 자동 플레이로도 이렇게 되니 너무 쉽다.

- 목표: 단순 자동 플레이 (팀·개인 훈련 돌려 쓰기, 장비·트레이너 안 씀) → 프로 주전, 평균 15~22점, 올스타 몇 번. 잘 키우면 (트레이너, 장비, 집, 특수능력, 피로 관리, 맞는 포지션) → 평균 25~32점, MVP 여러 번도 가능
- 자동 플레이 두 가지 (단순 / 잘 키우기)를 도구로 만들어서 둘 사이 차이를 숫자로 확인한다
- 수단
  - 종합 80이 넘으면 능력치 비용을 더 비싸게, 90부터는 아주 비싸게
  - 리그 에이스들을 더 강하게 (팀마다 스타 한 명은 종합 80 이상)
  - 한 명이 너무 넣으면 상대가 더블팀을 더 자주 붙는다
- 명예의 전당 기준은 바꾼 밸런스로 자동 플레이 다섯 번을 돌려 보고 다시 정한다 (잘 키운 커리어의 1/3 정도가 헌액되게)

### 기록 빈칸

- 해외에 있는 동안 국내 리그도 경기를 전부 빠르게 돌려서, 순위·시즌 기록·시상이 다 남게 한다
- 예전(v3) 세이브의 거쳐 간 팀 기록은 복원할 정보가 없어서 지금 팀만 남는다 (그대로 둔다)

## M12. 대학 진학, 성격, 아르바이트

### 대학 진학 (W2) ✅ 방향 / 🟡 세부

- 고3이 끝나면 고른다: **드래프트 신청** 또는 **대학 진학**
- 추천 세부
  - 대학은 최대 4년. 매년 끝에 드래프트를 신청할 수 있다 (얼리 엔트리)
  - 대학 제안 세 곳: 명문 (수준 높고 출전 경쟁), 중위권, 약체 (바로 주전). 고교 성적·인기로 제안이 달라진다
  - 대학 리그: 가상 대학 8팀, 정규 리그 + 챔피언전, 여름 대학 대회 하나. 경기는 고교처럼 관람
  - 장점: 성장할 시간이 생기고, 대학 수상이 지명 가치에 들어간다. 단점: 연봉이 늦게 나오고 나이 들어 데뷔한다
  - 드래프트 순위는 '대학 몇 학년, 몇 살'까지 같이 본다

### 성격 (M6) ✅ 1~2개

- 선수를 만들 때 하나 고르고, 커리어 중 이벤트로 하나가 더 생기거나 바뀐다
- 후보 8가지 (효과는 작게): 성실 (훈련 포인트 +), 승부욕 (클러치·공식전 컨디션), 낙천 (컨디션이 잘 안 떨어짐), 리더 (팀 친밀도·감독 신뢰가 빨리 오름), 쇼맨 (인기·화려한 덩크, 실책 조금 늘어남), 냉철 (침착성·자유투), 다혈질 (투지, 테크니컬·파울 늘어남), 소심 (큰 경기에서 긴장, 대신 연습 효율 +)
- 이벤트 선택지와 인터뷰 답이 성격에 따라 달라진다

### 고교 아르바이트 (T2)

- 고교 주간 행동에 추가. 돈을 조금 벌고 (고교생도 싼 장비를 살 수 있게) 피로가 쌓인다. 감독 신뢰가 조금 깎인다

## M13. 남은 기획

### 콤비 기술 (R6) ✅ 있음

- 친밀도 80 넘는 팀원과 콤비가 생긴다: 앨리웁, 픽앤롤, 킥아웃 3점, 기브앤고
- 둘이 같이 코트에 있으면 엔진이 그 플레이를 더 자주 고르고 조금 더 잘 된다. 성공하면 '콤비!' 컷인

### 연애 (R4) ✅ 선택적 가벼운 이벤트

- 설정에서 끌 수 있다 (기본 켜짐)
- 친구 행동·이벤트로 만나고, 호감도, 데이트 이벤트 몇 개. 효과는 컨디션과 정신 포인트 조금
- 은퇴하고 2세로 이어 하면 부모 칸에 배우자 이름도 나온다

### 3x3 길거리 대회 (L8) (정함: 빠르게 진행)

- **콘테스트처럼 화면에서 빠르게 진행** (경기마다 득점 흐름과 내 기록이 한 줄씩 나오는 방식). 비시즌 여름에 한 번, 상금과 인기
- 다른 안: 엔진에 하프코트 3대3 모드를 넣어서 진짜로 관람 (엔진이 5대5 전면 코트 기준이라 큰 작업, 따로 마일스톤 하나) / 빼기

### 전지훈련 (L8)

- 비시즌에 2주짜리 하나 고른다: 국내 산악훈련 (싸다, 피지컬), 해외 스킬캠프 (비싸다, 기술), 은사와 특훈 (정신)

### 훈련 미니게임 (T4) ✅ 몇몇 훈련에, 건너뛰기 가능

- 경기는 계속 순수 관람. 훈련만 직접 할 수 있다
- 개인 훈련 슈팅: 움직이는 게이지 멈추기 (자유투 타이밍 바), 드리블: 나오는 방향키 순서대로 누르기, 웨이트: 연타
- 결과에 따라 포인트 ×0.8~1.3. 건너뛰면 ×1.0 (손해 없음). 설정에서 아예 끌 수 있다

### 포지션 전향

- 능력치가 다른 포지션에 더 맞으면 감독이 전향을 제안한다. 받아들이면 선호 포지션이 바뀌고 몇 주 동안 적응 훈련 보너스
