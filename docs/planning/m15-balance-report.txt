  simple = 팀·개인·웨이트·영상 돌려 쓰기, 장비·트레이너 안 씀 / good = 은사·트레이너·피로 관리·장비
  AW=1이면 해마다 MVP·베스트 5 수상자(종합, 기록)를 같이 찍는다

바꾼 것
- MVP 점수 = 기록 점수 (득점 + 리바운드 1.2 + 어시스트 1.5 + 스틸·블록 2) + 팀 승리 × 0.6 + (종합 - 65) × 1.3
- 베스트 5 = 기록 + 승리 × 0.3 + (종합 - 65) × 0.8, 신인왕 = 기록 + 승리 × 0.2 + (종합 - 65) × 0.4
- 득점왕·리바운드왕·어시스트왕·수비상은 기록 그대로
- 엔진을 안 돌린 경기의 득점 분배: 에이스 쏠림 2.6 → 3.4 (리그 득점 1위 25~32점)
- 프로 리그를 만들 때 팀마다 에이스 능력치 +3
