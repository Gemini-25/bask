## 한 줄 요약

PC 브라우저에서 하는 2D 도트 농구 커리어 게임. 고1에서 시작해 고교 → 드래프트 → 국내 프로(10팀, 정규시즌 30경기) → 해외 리그까지 30시간 넘게 이어지는 한 선수의 커리어. 정해진 스토리 없이 라이벌·팬·부상·은사 같은 시스템 이벤트로 이야기가 생긴다. 경기는 10명이 자유 좌표 위에서 스스로 판단하며 움직이는 시뮬레이션을 실시간으로 본다.

- **능력치 개수 (S1 "20~25개" vs S3~S6에서 39개 전부 선택)**: 39개 전부 씀. 자율 이동 엔진(E1)에서는 가속, 박스아웃, 헬프 수비처럼 세밀한 능력치가 실제로 차이를 만들기 때문. 화면에는 카테고리별로 묶어서 보여주고 상세 탭에서 전부 (U5).
- **천재 배경 (M2 메모)**: 출신 배경에 "천재" 추가. 모든 능력치 최대로 시작하는 무쌍 모드.
- **선수 생성 (M1 "자유 포인트 배분")**: 배경 선택 + 자유 포인트 배분. 랜덤 요소 없음.

- **첫 버전 (P4 메모 "바로 제대로 된 버전")**: 버리는 프로토타입 없이 처음부터 진짜 구조로 짠다. 보이는 범위만 MVP(Z2)부터 작게 시작해서 계속 쌓는다.

## 2차 결정 (열린 질문 정리)

1. **경기 엔진 (E1)**: 아래 초안대로. 움직임은 자율, 결과는 능력치 확률.
2. **경기 중 개입 (I1)**: 완전 순수 관람. 선택지, 공 요청, 격려, 항의, 세리머니 선택은 없음 (I2·I3·I4는 적용 안 함).
3. **플레이 장소 (K6)**: HTML 파일 하나로 빌드해서 전달. 받아서 더블클릭하면 실행되고 인터넷 없이도 됨.
   - 새 버전은 같은 폴더에 같은 이름으로 덮어쓰면 브라우저 저장이 이어짐. 세이브 파일 내보내기·불러오기로 백업 (K4).
   - 버전이 바뀌어도 예전 세이브를 읽을 수 있게 세이브에 버전 번호를 넣음.
4. **애니메이션 (G4)**: 부위별 도트 + 코드 관절 애니메이션. 머리·몸·팔·다리 도트를 코드로 움직이고, 화면에 그릴 때 픽셀 격자에 맞춰서 도트 느낌을 유지.

### 경기 엔진 초안 (E1 자율 이동)

- 0.1초마다 10명 전원이 "어디로 갈지"를 정한다. 공격은 전술(픽앤롤 등)이 정해준 자리 + 빈 공간 찾기, 수비는 마크맨과 골대 사이 + 도움 수비.
- 공을 가진 선수는 0.3~0.5초마다 슛 / 패스 / 돌파 / 드리블 유지 중 하나를 고른다. 각 선택지에 점수를 매기는데, 농구 IQ가 높을수록 좋은 선택을 한다.
- 성공 여부는 확률로 판정: 능력치 + 거리 + 수비수와의 간격 + 체력 + 클러치 상황. 움직임은 자율, 결과는 주사위.
- 화면 없이 계산만 돌리면 한 경기가 1초 안에 끝남. 다른 팀 경기도 같은 엔진으로 돌리고, 1000경기를 돌려서 통계가 현실적인지 확인 (E10).
- 같은 시드면 같은 경기가 나오니까 (E9) 화면은 그 결과를 재생만 한다. 배속, 하이라이트, 리플레이가 여기서 나옴 (E2).
- 가장 큰 위험: 선수들이 공에 우르르 몰리는 "동네 축구" 현상. 그래서 원 + 등번호만으로 10명이 농구처럼 움직이는지를 맨 먼저 확인한다.
