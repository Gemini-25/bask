# M13 다음 설계 (M14~)

M13까지 기획 질문지에서 고른 것은 거의 다 들어갔다. 여기서는 (1) 인게임 에디터, (2) 결정했는데 아직 안 만든 것, (3) 밸런스에 남은 점, (4) 더 넓힐 것을 정리한다.

✅ = 정해진 것, 🟡 = 이번에 정할 것 (추천안을 먼저 적음)

### 이번에 정한 것 (2026-10-12)

- 에디터: **모든 선수**를 고친다 (월드 에디터·팀 이름은 안 함). **개발자 패널 탭**에서 연다
- MVP 문제: **상 기준을 바꾸고 리그를 조금 세게**
- 다음 할 것: **콘텐츠 늘리기**, **빠진 것 묶음**, 그리고 **덩크·드리블·슛 동작 많이 늘리기** (능력치·천재성·특성에 따라 나오는 빈도가 다르게. 인유어페이스 덩크, 컨택트 덩크, 컨택트 슛, 페이드어웨이, 스텝백 등)
- 여자 프로 리그, 은퇴 후 감독 모드는 이번엔 안 고름 (보류)
- 나머지 🟡 (치트 표시, 성격 개수)는 추천안대로
- 동작: **작은 실제 효과**가 있다. **능력치로 나오고, 관련 특수능력이 있으면 훨씬 자주**
- 천재성: **새 능력치 '센스' (40번째) + 특수능력 '천재' (★1~3) 둘 다**. 센스는 동작이 나오는 기본 빈도와 창의적인 플레이, '천재'는 그걸 크게 키운다. '천재' 배경은 처음부터 천재 ★
- 순서: **M14 에디터 → M15 밸런스 (MVP) → M16 동작 → M17 빠진 것 묶음 → M18 콘텐츠**

### 그 뒤 의견 (M16 중)

- 경기 중 선수 머리 위에 이름이나 번호 → M16에 넣음 (번호 / 이름 / 끔)
- 전부 99가 너무 약하다, 모든 방면에서 티가 나야 한다 → M16에 슈퍼스타 보정
- 엔진을 평가할 지표가 적다: 돌파 횟수, 어떤 동작에서 쏜 슛인지와 성공률, WAR, 공격·수비 그래비티 같은 현대 농구 지표. 게임 화면에 다 안 보여도 된다 → **M17 분석 지표**
- 특성을 더 다양하게 → **M18 성격·특수능력 늘리기**
- 하이라이트는 FM처럼 빨리 진행하다가 하이라이트 장면에서 1배속 → M16에 넣음
- 바뀐 순서: M17 분석 지표 → M18 성격·특수능력 → M19 빠진 것 묶음 → M20 콘텐츠

## 1. 인게임 에디터

지금 개발자 패널로 되는 것: 내 선수 능력치 39개 숫자, 키·체중·잠재력·나이, 특수능력 ★, 덩크 전부 열기. 리그 탭에서 다른 선수는 능력치 전부 ±5만.

### 무엇을 고치나 (정함: 모든 선수)

- **모든 선수**. 나, 팀원, 라이벌, 리그·해외·학교 선수 전부
  - 능력치 39개 (숫자 입력 + 슬라이더, 등급과 포지션별 종합이 바로 바뀌어 보임)
  - 특수능력 12개 ★0~3 (나쁜 버릇 포함), 덩크
  - 성격 8개 (내 선수. 에디터에선 2개 제한을 풀까는 아래)
  - 키·윙스팬·체중, 포지션, 나이, 등번호, 이름
  - 외형 (피부, 머리 모양·색, 신발, 헤어밴드, 슬리브)과 도트 미리보기
  - 내 선수만: 잠재력, 성장 타입, 콤비, 연애 상대, 감독 신뢰, 친밀도
- 더 넓은 안: **월드 에디터**. 위에 더해서 팀·학교·대학 이름, 도시, 색, 전술 (속도, 픽앤롤, 지역방어 등). 질문지 메모처럼 실명 팀·선수를 직접 넣을 수 있다
- 좁은 안: 내 선수만 (지금 패널을 키운 정도)

### 어디서 여나 (정함: 개발자 패널 탭)

- 개발자 패널에 **'에디터' 탭**. 선수를 고르면 큰 편집 창이 뜬다. 고를 곳: 팀 탭·박스스코어·리그 기록의 선수 이름 옆 ✏️ (패널을 열어 둔 동안만 보임)
- 다른 안: 타이틀 화면에 따로 '에디터' 메뉴 (커리어를 시작하기 전에 세계를 고친다)
- 둘 다: 커리어 안에서는 패널 탭, 타이틀에서는 월드만

### 고친 것은 어디에 남나 🟡

- 추천: 선수 편집은 그 커리어 세이브에. 월드 편집 (팀 이름·색·전술)은 브라우저에 '월드 파일'로 따로 저장해서 **새 커리어에도 적용**, 내보내기·불러오기 가능
- 되돌리기: 편집 창마다 '처음 값으로' 버튼

### 치트 표시 🟡

- 추천: 내 선수를 고치면 🔧 (지금처럼). 다른 선수·팀 이름·색·외형만 고치면 표시 안 함
- 다른 안: 뭐든 고치면 🔧 / 표시 안 함

### 성격 개수 🟡

- 추천: 에디터에서는 2개 제한 없이 8개 중 아무거나 (서로 반대인 다혈질·냉철도 같이). 게임 안에서 생기는 건 계속 2개까지
- 다른 안: 에디터도 2개까지

## 2. 동작 크게 늘리기 (새 요청)

지금 있는 것: 슛 종류 6가지 (덩크, 레이업, 플로터, 훅, 미드레인지, 3점), 덩크 10가지 (경기용 8 + 콘테스트용 2), 드리블 기술 5가지 (크로스오버, 비하인드 백, 레그 스루, 스핀, 헤지테이션). 드리블 기술은 지금 보기만 하는 것 (결과는 같음).

### 넣을 동작 (안)

- 덩크: **인유어페이스** (블록하러 뜬 수비 위로 찍는다), **컨택트 덩크** (몸싸움을 이기고 찍는다, 앤드원 잘 남), **풋백 덩크** (공격 리바운드를 바로), 크레들, 원핸드 리버스 앨리웁
- 점프슛: **페이드어웨이**, **스텝백** (미드레인지·3점), 사이드스텝 3점, 턴어라운드 페이더 (포스트), 원레그 페이더, 헤지테이션 풀업, 캐치앤슛 퀵 릴리즈, **컨택트 슛** (부딪히면서 던진다, 앤드원), 뱅크샷, 스카이훅
- 레이업: **유로스텝**, 스쿱, 리버스 레이업, 핑거롤, 투핸드 파워 레이업, 더블클러치
- 드리블: 인앤아웃, 셰이크 앤 베이크, 스냅백, 킬러 크로스 (크로스 두 번), 스핀 → 스텝백 같은 이어 하기
- 덤: 체이스다운 블록 (뒤에서 쫓아가 찍기), 스트립 스틸, 노룩·비하인드 백 패스

### 얼마나 자주 나오나

동작마다 조건과 무게를 둔다.

- 관련 능력치가 높을수록 자주 (스텝백 = 볼핸들링·민첩성·3점, 인유어페이스 = 점프력·덩크·근력·승부욕)
- 특수능력이 있으면 훨씬 자주 (앵클 브레이커 → 드리블 기술·스텝백, 퀵 릴리즈 → 캐치앤슛). 동작용 특수능력도 새로 (포스터라이저, 스텝백 장인, 페이드어웨이 장인, 유로스텝 마스터 등)
- 성격: 쇼맨 → 화려한 동작, 냉철 → 기본기 (뱅크샷·핑거롤), 다혈질 → 인유어페이스·컨택트
- 천재성: 센스 능력치가 기본 빈도, 특수능력 '천재'가 있으면 화려한 동작이 크게 늘어난다 (정함)

### 결과에 영향을 주나 (정함: 작은 실제 효과)

- **동작마다 작은 실제 효과**. 스텝백은 수비와 거리가 벌어지지만 조금 덜 정확, 페이드어웨이는 블록을 거의 안 당하지만 덜 정확, 유로스텝은 견제를 줄임, 컨택트는 앤드원이 잘 남, 인유어페이스는 블록을 이기고 넣는 판정. 엔진이 상황에 맞는 동작을 고른다
- 다른 안: 보기만 (결과는 지금과 같고 그림만 다름)

- 여자 프로 리그: 리그 하나를 더 만드는 일이라 따로 한 마일스톤 (팀 10개, 선수 키 분포, 국가대표·해외 리그도 여자용)
- 그래픽·BGM 교체: 쓸 도트·곡 파일이 있어야 한다. 파일을 주면 넣는 작업은 내가 한다

## 4. 밸런스에 남은 점 (정함: 상 기준 + 리그 조금 세게, M15에서 함)

- 종합 62~65 선수도 팀에서 득점이 몰리면 MVP를 받는다. 단순 자동 플레이도 시드에 따라 프로 2년차 MVP
- 추천: **MVP·베스트 5를 득점만이 아니라 팀 성적과 종합 효율(득점·리바운드·어시스트·수비)로** 뽑고, 리그 상위 선수 능력치를 조금 올린다. 목표: 단순 플레이는 올스타·베스트 5까지, MVP는 잘 키웠을 때
- 다른 안: 리그만 세게 (상 기준은 그대로) / 그대로 둔다

## 5. 더 넓힐 것 (아이디어)

- 콘텐츠: 이벤트 32개 → 50개 이상, 특수능력 12개 → 20개, 덩크 10개 → 14개
- 은퇴 후: 코치·감독으로 2세 팀을 맡는 짧은 모드 (질문지 C1에서 안 골랐던 것이라 원하면)
- 경기 중 개입은 순수 관람으로 정했으니 넣지 않는다 ✅
