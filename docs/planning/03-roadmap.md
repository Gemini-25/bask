# 로드맵

순서는 Z3(경기 엔진 먼저), 그래픽은 Z4(임시 도형으로 시작) 기준.
모든 마일스톤은 버리는 시험판이 아니라 계속 쌓아가는 진짜 코드다 (P4 메모).
마일스톤이 끝날 때마다 HTML 파일 하나를 전달하고, 플레이 피드백을 받아 다음으로 넘어간다 (P5).

## M0. 기반 ✅

- TypeScript + Vite + Phaser 프로젝트, HTML 파일 하나로 빌드
- 선수·팀 데이터 구조, 능력치 39개, 시드 고정 랜덤
- 엔진 테스트 환경

## M1. 경기 엔진 1: 농구처럼 움직이나 ✅

- 위에서 본 코트에 원 + 등번호로 10명 표시
- 0.1초 단위 자율 이동: 대인방어, 공격 자리 잡기, 빈 공간 찾기
- 공 가진 선수의 판단: 슛 / 패스 / 돌파 / 드리블
- 슛, 패스, 리바운드, 턴오버, 24초 샷클락, 쿼터
- 공격 플레이: 아이솔레이션, 픽앤롤, 속공
- 확인할 것: 선수들이 공에 몰리지 않고 농구처럼 보이는가

M1에서 실제로 들어간 것:

- 공격 전술 4가지: 픽앤롤(팝 포함), 아이솔레이션, 포스트업, 모션 + 컷인
- 수비: 대인방어, 도움 수비(코너·좋은 슈터한테선 덜 감), 림 프로텍션, 드롭 커버리지, 클로즈아웃
- 판정: 수비 견제 정도에 따른 슛 성공률 (NBA 슛 추적 데이터 기준), 블록, 리바운드 경합, 패스 가로채기, 드리블 스틸, 앵클 브레이커
- 득점이 한 명에게 너무 몰리면 수비가 집중 견제 (경기 최다 득점 평균 29점)
- 결과: [M1 밸런스 리포트](m1-balance-report.txt). 자유투가 없는 걸 빼면 대부분 실제 리그 범위 안

M2로 넘긴 숙제:

- 공격 리바운드 비율 32% (목표 27~30%)
- 2점 성공률 50% (목표 53~56%): 골밑 파울·자유투가 들어가면 다시 맞춘다
- 공격 횟수 66 (목표 71~73), 슛까지 평균 18.5초로 조금 느림
- 득점 쏠림 방지는 지금 단순한 보정. 더블팀·스위치가 들어가면 그걸로 바꾼다

## M2. 경기 엔진 2: 숫자가 현실적인가 ✅

- 파울·자유투·팀파울 보너스(FIBA 5번째부터), 5반칙·테크니컬 2개 퇴장, 앤드원, 차징, 무빙 스크린, 리바운드 다툼 파울, 막판 작전상 파울
- 체력: 뛴 만큼 줄고 벤치·쿼터 사이에 회복, 지치면 느려지고 슛이 흔들린다
- AI 감독: 체력·반칙 수·출전 시간 계획으로 교체, 쉬고 온 주전 복귀, 막판 접전엔 주전 기용, 큰 점수차면 벤치 멤버
- 타임아웃: 상대 흐름 끊기, 막판 작전, 하프 막판 (FIBA 전반 2·후반 3·연장 1), 마지막 2분 타임아웃 후 프런트코트 인바운드
- 8초 바이얼레이션, 이기고 있는 팀은 막판에 시간 끌기
- 수비: 수비 잘하는 선수가 상대 에이스 전담, 픽앤롤 스위치(미스매치 생기면 포스트업), 2-3·3-2 지역방어, 득점 후 풀코트 프레스(함정 수비), 포스트·에이스 더블팀
- 공격: 오프스크린(다운스크린 받고 3점), 드리블 핸드오프, 앨리웁
- 1000경기 리포트에 자유투·파울·출전 시간·퇴장·타임아웃 추가
- 화면: 교체된 선수 번호, 파울·자유투·앤드원·앨리웁·테크니컬·퇴장 연출, 자유투 라인업, 타임아웃 때 벤치로 이동, 팀파울·남은 타임아웃·수비 전술 표시, 지친 선수 체력 막대, 출전 시간·파울·자유투·± 박스스코어
- 결과: [M2 밸런스 리포트](m2-balance-report.txt). 대부분 실제 리그 범위 안

M3 이후로 넘긴 숙제:

- 자유투 시도 17.7 (목표 19~22), 득점 84 (목표 80~82), 공격 횟수 75 (목표 71~73)
- 경기 최다 득점 평균 30점 (목표 24~28)
- 교체는 데드볼에 그 자리에서 바뀐다. 벤치에서 걸어 들어오는 연출은 M6
- 승리 확률 그래프 (V7)

## M3. 관람 화면

- 3/4 쿼터뷰 코트, 전체 고정 + 중요 장면 줌인
- 부위별 도트 캐릭터 첫 버전 (달리기, 드리블, 패스, 점프슛, 레이업, 리바운드)
- 공 포물선, 그림자, 림아웃
- 배속, 내 선수 출전 시간만, 하이라이트만, 결과만
- 스코어보드, 박스스코어, 샷차트, 체력 게이지, 승리 확률 그래프
- 말풍선, 득점 팝업, 컷인, 슬로모션
