# 로드맵

순서는 Z3(경기 엔진 먼저), 그래픽은 Z4(임시 도형으로 시작) 기준.
모든 마일스톤은 버리는 시험판이 아니라 계속 쌓아가는 진짜 코드다 (P4 메모).
마일스톤이 끝날 때마다 HTML 파일 하나를 전달하고, 플레이 피드백을 받아 다음으로 넘어간다 (P5).

## M0. 기반 ✅

- TypeScript + Vite + Phaser 프로젝트, HTML 파일 하나로 빌드
- 선수·팀 데이터 구조, 능력치 39개, 시드 고정 랜덤
- 엔진 테스트 환경

## M1. 경기 엔진 1: 농구처럼 움직이나 ✅

- 위에서 본 코트에 원 + 등번호로 10명 표시
- 0.1초 단위 자율 이동: 대인방어, 공격 자리 잡기, 빈 공간 찾기
- 공 가진 선수의 판단: 슛 / 패스 / 돌파 / 드리블
- 슛, 패스, 리바운드, 턴오버, 24초 샷클락, 쿼터
- 공격 플레이: 아이솔레이션, 픽앤롤, 속공
- 확인할 것: 선수들이 공에 몰리지 않고 농구처럼 보이는가

M1에서 실제로 들어간 것:

- 공격 전술 4가지: 픽앤롤(팝 포함), 아이솔레이션, 포스트업, 모션 + 컷인
- 수비: 대인방어, 도움 수비(코너·좋은 슈터한테선 덜 감), 림 프로텍션, 드롭 커버리지, 클로즈아웃
- 판정: 수비 견제 정도에 따른 슛 성공률 (NBA 슛 추적 데이터 기준), 블록, 리바운드 경합, 패스 가로채기, 드리블 스틸, 앵클 브레이커
- 득점이 한 명에게 너무 몰리면 수비가 집중 견제 (경기 최다 득점 평균 29점)
- 결과: [M1 밸런스 리포트](m1-balance-report.txt). 자유투가 없는 걸 빼면 대부분 실제 리그 범위 안

M2로 넘긴 숙제:

- 2점 성공률 50% (목표 53~56%): 골밑 파울·자유투가 들어가면 다시 맞춘다
- 공격 횟수 66 (목표 71~73), 슛까지 평균 18.5초로 조금 느림
- 득점 쏠림 방지는 지금 단순한 보정. 더블팀·스위치가 들어가면 그걸로 바꾼다

- 부위별 도트 캐릭터 첫 버전 (달리기, 드리블, 패스, 점프슛, 레이업, 리바운드)
- 공 포물선, 그림자, 림아웃
- 배속, 내 선수 출전 시간만, 하이라이트만, 결과만
- 스코어보드, 박스스코어, 샷차트, 체력 게이지, 승리 확률 그래프
- 말풍선, 득점 팝업, 컷인, 슬로모션

M3에서 실제로 들어간 것:

- 3/4 쿼터뷰 경기장: 팀 색 관중석(득점하면 들썩이고 큰 플레이엔 파도타기), 광고판, 나무 바닥, 양쪽 벤치(앉아 있는 선수가 일어나 환호), 기록석, 전광판, 골대 지지대
- 부위별 도트 캐릭터: 몸통·팔·다리·머리를 코드로 그리고 관절 각도로 움직인다. 동작 17가지 (서 있기, 드리블, 볼 잡기, 점프슛, 레이업, 덩크, 패스, 리바운드, 블록, 슛 견제, 수비 자세, 스크린, 앵클 브레이크에 휘청, 세리머니, 자유투, 포스트업, 림 매달리기), 앞·옆·뒤 방향
- 선수마다 피부색·머리 모양 7종·머리색·신발·헤어밴드·팔토시 조합 (이름으로 정해져서 항상 같은 얼굴)
- 엔진이 선수별 동작과 점프 높이도 기록 → 화면은 그대로 재생
- 연출: 덩크 줌인, 앨리웁·버저비터·막판 결정적인 슛·고른 선수의 덩크/3점 컷인, 버저비터 슬로모션, 스크린 말풍선, 득점·블록·스틸·파울 팝업, 그물 흔들림, 지친 선수 땀
- 보는 방법: 전체 / 고른 선수가 코트에 있을 때만 / 하이라이트만 (덩크·3점·앨리웁·앤드원·블록·스틸·막판 5점 차 이내 접전, 경기당 50개쯤), 결과 보기
- 패널: 샷차트 (팀별로 한쪽 골대에 모아서, 구역별 성공률 표, 고른 선수 강조), 승리 확률 흐름 (300경기로 계수 맞춤, 최대 리드·역전·동점 횟수). 둘 다 지금 보고 있는 시점까지만 그린다
- 개발용 도트 시트 `sprites.html`: 모든 동작 × 방향을 한 화면에

## M4. 육성 루프 (첫 플레이 버전) ✅

- 선수 생성: 배경 선택 (천재 포함) + 자유 포인트 배분, 외형 조합
- 주간 행동 → 경험치 포인트 → 능력치 투자, 실전 사용 보너스
- 피로와 부상 확률, 컨디션
- 연습경기 관람 → 성장 결과 화면
- 저장, 세이브 파일 내보내기·불러오기

M4에서 실제로 들어간 것:

- 화면: 타이틀(저장 슬롯 3개) → 선수 만들기 → 홈(선수 카드 + 이번 주 / 능력치 / 팀 / 기록) → 연습경기 관람 → 성장 결과. 프로 리그 데모 관람은 타이틀에 남김
- 선수 만들기: 이름·등번호·성별(리그 분리)·선호 포지션, 출신 배경 7가지 (평범한 동네 아이, 명문가 2세, 길거리, 늦게 시작한 장신, 타 종목 전향, 해외 유학파, 천재), 성장 타입 3가지 (조숙·보통·만성), 키 ±8cm (크면 느려지고 골밑이 세짐), 체형 3가지, 겉모습 (피부·머리 모양 7·머리색·신발·헤어밴드·팔토시), 학교 10곳 (전력 별점), 자유 포인트 배분 (상한 60, 자동 배분)
- 포인트 3종 (피지컬 / 기술 / 정신). 능력치를 1 올리는 비용은 높을수록 비싸고, 잠재력을 넘으면 2배 (소프트 캡)
- 주간 행동 8가지: 팀 훈련, 개인 훈련 (슈팅·돌파·골밑·수비·패스 중 집중 → 그 능력치 경험치), 웨이트, 영상 분석, 길거리 3x3 (가끔 고수에게 배움), 친구와 놀기, 휴식, 재활 (다쳤을 때만)
- 피로: 훈련으로 쌓이고 매주 조금씩 풀림 (지구력·회복력 영향). 피로가 높을수록 부상 확률이 제곱으로 오름. 부상 6종 (1주 ~ 30주)
- 컨디션 5단계: 훈련 효율 ×0.6~1.3, 경기 중 능력치 −5~+4
- 키는 고교 동안 조금씩 자람 (최종 키는 ±2cm 범위로 공개)
- 연습경기 (4주마다): 감독이 포지션별로 주전을 고르고, 연습경기에선 신입생에게 최소 15분을 준다. 누적 피로만큼 체력이 덜 찬 채로 시작
- 실전 사용 보너스: 쏜 슛 종류, 자유투, 리바운드, 어시스트, 스틸, 블록, 출전 시간이 각 능력치 경험치가 된다. 다 차면 저절로 +1
- 경기 평가 S~D (게임 스코어를 30분 기준으로), 감독 한마디, 포인트 보상
- 저장: 브라우저 슬롯 3개, 매주·매 경기 자동 저장, 세이브 파일 내보내기·불러오기 (버전 번호 포함)
- 결과: [M4 성장 리포트](m4-growth-report.txt). 자동 전략으로 1학년 1년 동안 종합 +9~13 (평범한 아이 44 → 53, 고교 주전급 50 안팎)

M5 이후로 넘긴 숙제:

- 감독 신뢰도, 친밀도, 이벤트, 성격 (M5)

## M5. 고교 1년 ✅

- 1년 3~4개 대회, 지역·전국 토너먼트
- 팀원 친밀도, 감독 신뢰도 → AI 감독의 출전 시간 결정
- 라이벌, 은사, 이벤트 시스템 (데이터 파일)
- 특수능력과 등급 진화
- 작은 메인 맵 + 하단 메뉴

M5에서 실제로 들어간 것:

- 시즌 (48주, 3월 시작): 춘계 연맹전 (4월, 8강 토너먼트), 협회장기 (7~8월, 10팀 두 조 리그 → 4강), 전국체전 (10월, 8강), 왕중왕전 (12월, 시즌 성적 상위 4팀) + 대회 없는 달 연습경기 7번. 내 경기는 엔진으로, 남의 경기는 전력 차 + 정규분포로 바로 결과
- 대회 성적 보상 (우승·준우승·4강·8강), 일정 탭에 대진표와 조별 순위
- 학교 전력 차이를 좁혀서 약한 학교를 골라도 4강·8강 싸움이 된다
- 해가 바뀌면 3학년 졸업, 진급, 신입생 입학, 상대 학교 선수단도 새로. 팀원은 달마다 조금씩 큰다
- 감독 신뢰도 (0~100): 팀 훈련·영상 분석·좋은 경기로 오르고, 길거리 농구·나쁜 경기로 내린다. 공식전 출전 순서와 교체에 ±5 반영. 공식전엔 연습경기 같은 최소 출전 시간이 없다
- 팀원 친밀도: 팀 훈련·친구와 놀기로 오른다. 팀 탭에 하트, 이벤트 조건
- 라이벌: 다른 강호 학교의 같은 포지션 신입생. 매달 크고, 그 학교와 붙으면 상대 명단에 나온다. 맞대결 전적, 결과 화면에 라이벌 기록
- 은사: 길거리 3x3에서 가끔 만나는 은퇴한 전설. 만나면 '은사 특훈' (한 달에 한 번, 고른 분야 경험치 2배 이상)
- 이벤트 20가지 (데이터 파일 `src/career/events.ts`): 조건, 무게, 쿨타임, 선택지별 효과 (포인트·신뢰·피로·컨디션·친밀도·경험치·확률 분기). 1년에 15~19번
- 특수능력 12가지: 좋은 능력 8 (클러치 슈터, 앵클 브레이커, 철벽 수비, 리바운드 머신, 퀵 릴리즈, 노룩 패스, 인 더 존, 분위기 메이커) ★1~3 진화, 나쁜 버릇 4 (유리몸, 새가슴, 자유투 공포증, 파울 트러블). 통산 기록 + 능력치 조건, 경기 엔진에 효과 반영. 배경별 시작 능력, 천재는 전부 ★3
- 홈: 작은 마을 맵 (학교 체육관, 공원 코트, 집, 분식집, 병원). 건물을 누르면 그곳 행동을 강조하고, 행동을 고르면 그 건물까지 걸어간다. 하단 메뉴 6개 (행동, 능력치, 팀, 일정, 특수능력, 기록)
- 세이브 v2 (v1 세이브는 자동 변환, 지난 대회 경기는 빠르게 채움)

## M7. 고교 3년 → 드래프트 → 프로 ✅

- 키 성장, 포지션 변화

M7에서 실제로 들어간 것:

- 고3이 끝나면 드래프트: 프로 10팀이 지난 시즌 꼴찌부터 2라운드 20명. 내 지명 가치 = 종합 능력치 + 잠재력 + 고교 공식전 승리 + 인기. 라이벌도 같이 뽑힌다. 1순위부터 한 명씩 불리는 입단식 화면
- 신인 계약 (1순위 9천만 ~ 2라운드, 2시즌), 연봉은 매주 들어온다. 계약이 끝나면 재계약 협상: 지금 팀 / 다른 팀 두 곳(FA) / 더 달라고 하기 (인기가 높을수록 성공)
- 프로 시즌 (48주): 비시즌 훈련 → 프리시즌 연습경기 2번 → 정규시즌 27경기 (9팀과 3번씩) → 6강(3전 2선승)·4강(5전 3선승)·챔피언 결정전(7전 4선승). 플레이오프는 한 주에 경기가 여러 번 (경기 대기열)
- 살아있는 리그: 모든 선수에게 나이. 해마다 나이에 따라 크거나 늙고 (30대엔 피지컬이 먼저), 베테랑 은퇴, 신인 드래프트, 몇 명은 다른 팀으로. 나도 서른이 넘으면 몸이 늙는다
- 돈: 장비 6가지 (농구화, 슈팅 슬리브, 무릎 보호대, 컴프레션 웨어, 고글 → 경기 중 능력치 보너스·부상 감소), 집 꾸미기 5가지 (침대, 홈짐, 영상실, 마당 골대, 아쿠아 테라피 → 훈련·휴식 효과)
- 프로 행동: 개인 트레이너 (200만 원, 경험치 1.5배, 덜 다친다), 광고 촬영 (돈 + 인기, 감독 신뢰 조금 깎임)
- 인기 0~100: 경기 평가·승리·덩크와 버저비터로 오르고 매주 조금 식는다. 경기 뒤 SNS 반응 글, 잘하거나 공식전이면 인터뷰 선택지 (겸손 / 자신감 / 다음 경기)
- 프로 이벤트: 트레이드 소문 (감독 신뢰가 낮으면, 트레이드 요청 가능), 팬레터, 신인의 벽, 스폰서 계약
- 화면: 생활 탭 (연봉·계약·돈·인기, 장비·집 상점, SNS), 일정 탭은 리그 순위·다음 경기·플레이오프 대진·역대 시즌, 팀 탭은 나이, 마을 맵은 구단 훈련장
- 키 성장은 고교 동안, 포지션은 감독이 팀 사정에 맞춰 정한다 (팀 탭)
- 성장 속도를 다시 맞췄다: 고교 1년에 종합 +5~7, 드래프트 때 50~57 (자유 포인트를 잘 쓰면 60대), 프로에서 해마다 +4~6. 득점이 한 명에게 너무 몰리면 동료를 더 찾는다
- 세이브 v3 (v1·v2 자동 변환). 프로 세이브는 250KB 안팎
- 결과: [M7 커리어 리포트](m7-pro-report.txt)

M8에서 실제로 들어간 것:

- 기록 탭: 트로피, 시즌별 기록 (고교 1~3학년, 프로 N시즌), 경기 목록
- 올스타 위크엔드 (정규시즌 한가운데, 그 주는 리그 경기가 없다): 리그 상위 24명이 드림팀·매직팀으로. 3점 콘테스트 (6명 예선 → 3명 결승, 25개 중 머니볼 2점, 한 개씩 들어가는 화면), 덩크 콘테스트 (4명 2번씩 → 2명 결승, 심사위원 다섯 명 점수, 같은 덩크 또 하면 감점). 뽑히면 올스타전을 실제로 치르고 MVP를 뽑는다. 우승 상금 1000만 원
- 국가대표 아시아컵 (비시즌 4월): 국내 리그 최고 12명에 들면 소집. 조별리그 3경기에서 2승이면 결승 (보통 호주). 대표팀 경기는 감독 신뢰에 영향 없음
- 해외 리그: 재계약 때 종합 72 이상이거나 MVP를 받았으면 해외 구단 제안 (연봉 1.7배). 가상 해외 리그 10팀은 더 강하고 키가 크고 외국 이름. 쿼터 12분, 6반칙 퇴장 (엔진 옵션 `foulOut`). 해외에 있는 동안 국내 리그도 해마다 나이·은퇴·신인이 돌아간다. 해외에서 재계약할 때는 국내 복귀 제안
- 계약: 서른이 넘으면 계약 기간이 짧아진다. 거쳐 간 팀 기록
- 은퇴: 31살부터 계약이 끝나면 은퇴할지 묻는다 (생활 탭에서 언제든 은퇴 선언 가능), 39살이면 무조건. 은퇴식 화면에 통산 기록·트로피·최고 종합
- 명예의 전당 점수 = 트로피 점수 (MVP 12, 우승 6, 신인왕·타이틀·베스트 5 3, 올스타 2, 아시아컵 우승 4, 해외는 1.5배) + 통산 득점/500. 50점 넘으면 헌액. 한 팀에서 5시즌 이상 뛰었거나 헌액되면 그 팀이 등번호 영구결번
- 2세 계승: 은퇴하면 같은 슬롯에서 2세로 새 커리어. 부모 성을 물려받고, 자유 포인트 +6~30, 잠재력 +2~4, 용돈 (부모 돈의 10%, 최대 2억)
- 업적 26개 (첫 승, 40점, 트리플 더블, 1순위, 올스타, 콘테스트, MVP, 우승, 태극마크, 해외 진출, 10억, 꿈의 집, 명예의 전당, 영구결번, 대를 잇다 …). 명예의 전당과 업적은 슬롯과 상관없이 브라우저에 남고 타이틀에 보인다
- 세이브 v4 (v1~v3 자동 변환). 13시즌 커리어 세이브는 600KB 안팎
- 결과: [M8 커리어 리포트](m8-career-report.txt) (고교 3년 → 프로 13시즌, 해외 두 번, 은퇴)

## M9. 개발자 패널 ✅

- 백틱(`) 키나 머리글 BASK 로고 5번 클릭으로 연다. 한 번 열면 머리글에 🔧 버튼이 남는다. 넓은 화면에선 게임 화면이 왼쪽으로 비켜서 겹치지 않고, ▲로 접으면 머리만 남는다
- 선수: 능력치 39개 직접 입력, 전부 ±5 / 전부 N, 키·체중·잠재력·나이·피로·컨디션·감독 신뢰·인기·돈, 포인트 +20, 돈 +1억, 부상 치료, 친밀도 100, 덩크 전부 열기, 특수능력 ★ 주기/빼기
- 시간: N주 자동 진행 (자동 돌려 쓰기 또는 한 행동 반복, 포인트 자동 투자), 이정표까지 점프 (다음 경기 직전, 드래프트, 올스타, 국가대표, 해 넘김, 재계약, 은퇴 결정). 경기는 결과만, 이벤트는 첫 선택지. 멈추기 버튼, 진행 기록
- 이벤트: 이벤트 24개를 조건 없이 바로, 올스타 위크엔드·국가대표 소집·재계약·해외 제안·지난 시상식·은퇴 결정을 지금
- 경기: 슛·자유투 성공 확률과 견제 표시 (코트와 문자 중계), 선수 발밑 체력 숫자, 배속 32x·64x·100x, 다른 시드로 다시 / 시드 넣어서 경기, 데모 경기 시드 지정
- 리그: 아무 팀 선수단 (나이·종합·시즌 득점) 보고 능력치 ±5, 라이벌 ±5
- 세이브: JSON 복사·파일, 빠른 스냅샷 3개 (찍기/되돌리기), 업적·명예의 전당 지우기
- 값을 바꾸거나 강제 발동하면 그 커리어에 🔧 표시. 머리글, 명예의 전당, 업적(🔧)에 남는다. 보기 옵션과 자동 진행은 표시 안 함
- 엔진은 슛·자유투 이벤트에 성공 확률과 견제를 같이 적는다 (같은 시드면 결과는 예전과 같다)
- 자동 진행 규칙은 `src/career/autoplay.ts` 하나로 모았다 (M11 밸런스 도구도 이걸 쓴다)

## M10. 연출 ✅

- 스틸: 드리블 스틸의 절반쯤은 손끝으로 쳐내서 루즈볼이 된다. 양 팀이 뛰어가고 (몸을 던지기도 한다) 수비가 잡으면 쳐낸 선수의 스틸, 공격이 잡으면 공격이 이어지고, 밖으로 나가면 공격팀 공. 가로챈 패스도 30%는 손만 맞고 튄다
- 블록: 관중석까지 날려 버리기 (공격팀 공으로 다시) / 블록한 선수가 바로 잡기 / 튀어서 리바운드 다툼
- 드리블 기술 5가지: 크로스오버, 비하인드 백, 레그 스루, 스핀 무브, 헤지테이션. 돌파 첫발과 수비와 마주 섰을 때, 볼 핸들링이 좋을수록 화려하게. 공이 몸 주위를 실제로 오간다. 앵클 브레이크 문자 중계에 기술 이름
- 덩크 10가지: 더블 클러치, 엘보우 행 추가. 비트윈 더 레그, 자유투 라인 덩크는 덩크 콘테스트 전용
- 응원단 (생활 탭): 등번호 현수막, 응원 깃발, 이름 응원 구호 (관중 말풍선), 마스코트 인형탈, 치어리더, 전광판 내 등번호. 하나에 홈 경기 인기 +5%
- 프로 경기장 천장: 홈팀 우승 시즌 배너, 영구결번 유니폼 (다른 커리어의 명예의 전당 기록도). 내 홈 경기는 인기만큼 관중석이 찬다
- BGM 6곡 (코드로 작곡): 타이틀, 고교 홈, 프로 홈, 플레이오프 (시즌 막판·플레이오프 경기 전), 시상식·드래프트, 은퇴
- 무대 장면: 덩크 콘테스트를 코트에서 도트로 (도움닫기 → 덩크 → 림에 매달리기, 심사위원석, 카메라 플래시), 우승 세리머니 (트로피, 팀원, 꽃가루), 시상식 단상 (조명, 사회자), 드래프트 무대 (구단 모자, 악수)
- 시즌이 끝나면 시즌 요약 카드 (경기당 기록, 슛 성공률, 최고 경기, 팀 성적, 받은 상)
- 경기 기록은 이전과 거의 같다 ([M10 밸런스 리포트](m10-balance-report.txt): 스틸 6.9, 턴오버 13.7)

## M11. 밸런스 ✅

- 목표: 키운 만큼 차이 나게. [M11 밸런스 리포트](m11-balance-report.txt)에 자동 플레이 세 가지 (대충 / 잘 키우기 / 포인트 골고루)를 비교해 뒀다
  - 대충 (훈련 돌려 쓰기): 신인 땐 벤치~식스맨 (7~19점), 프로 3년차쯤 주전·올스타, 득점왕은 가끔, MVP는 6시즌에 0~5번
  - 잘 키우기 (은사·트레이너·피로 관리·장비): 신인 첫해부터 MVP급 (29~34점), 6시즌에 MVP 3~5번, 종합 83~84
  - 포인트를 아무 데나 골고루: 종합이 거의 안 올라 프로에서 벤치
- 능력치 비용: 60부터 단계적으로 비싸진다 (60 ×1.3, 70 ×1.8, 80 ×2.6, 90 ×3.6, 잠재력을 넘으면 그 두 배). 은사·트레이너 특훈 경험치는 포인트와 따로라서 잘 키우면 벽을 넘는다
- 감독 신뢰: 높을수록 덜 오른다 (프로 첫 시즌에 100이 되던 것을 몇 시즌에 걸쳐)
- 인기: 높을수록 덜 오르고, 고교 땐 40 근처에서 멈추고, 높을수록 빨리 식는다. 고교 끝 10~25, 프로 2~3년차 40~70, 정상급 80~90
- 경기 엔진: 한 선수가 팀 슛의 21%를 넘기면 동료를 더 찾는다 (리그 전체 득점이 한 명에게 덜 몰린다). 리그 평균 득점 80.6, 공격 횟수 72.2, 경기 최다 득점 28.1
- 명예의 전당 기준 50 → 100점
- 해외에 있는 동안 국내 리그 (그리고 돌아온 뒤 해외 리그)도 정규시즌·플레이오프·시상까지 다 치른다
- 자동 플레이 도구: `tools/balance.ts`, 개발자 패널 시간 탭과 같은 `src/career/autoplay.ts` (잘 키우기 규칙 포함)

## M12. 대학 진학, 성격, 아르바이트 ✅

- 진로 (W2): 고3이 끝나면 드래프트 신청 (고졸 프로) 또는 대학 세 곳 중 하나 (명문 / 중위권 / 약체, 고교 성적과 인기가 좋아야 명문이 부른다)
- 대학 10곳 (가상), 대학 대회 4개: 춘계대회 → 대학리그 (조별) → 농구대잔치 → 대학 왕중왕전. 경기는 고교처럼 관람
- 대학은 4학년까지, 4학년 선배가 주축. 학년이 끝날 때마다 얼리 엔트리 (드래프트) 또는 1년 더. 4학년을 마치면 드래프트
- 대학 대회 우승은 트로피 (명예의 전당 점수 1점), 업적 '대학 정상'. 대학 인기는 55 근처에서 멈춘다
- 날짜와 기록표: 고교 N학년 → (고교 졸업) → 대학 N학년 → 프로 N년차. 프로가 된 해를 기억한다 (proFromYear)
- 라이벌은 다른 대학으로 가고, 같은 해 드래프트에 나온다
- 성격 (M6 결정 1~2개): 성실 (훈련 포인트 +8%), 승부욕 (공식전 승부욕·침착성), 낙천 (컨디션이 잘 안 떨어짐), 리더 (친밀도 +30%, 감독 신뢰 +15%), 쇼맨 (인기 +25%, 덩크), 냉철 (침착성·자유투·집중력), 다혈질 (승부욕·허슬 크게, 침착성·IQ 낮게), 소심 (큰 경기 긴장, 혼자 훈련 +10%). 만들 때 하나, 이벤트 '달라진 나'·'큰 경기의 무게'로 하나 더. 성격마다 인터뷰 답이 하나 더 생긴다
- 아르바이트 (T2): 고교·대학 주간 행동. 돈 30~50만 원, 피로, 감독 신뢰 -0.4. 고교·대학 때도 장비는 살 수 있다
- 세이브 v5 (v1~v4 자동 변환)

## M13. 콤비, 연애, 3x3·전지훈련, 미니게임, 포지션 전향 ✅

- 콤비 기술 (R6): 친밀도 80 넘는 팀원과 콤비 (두 명까지). 앨리웁 / 픽앤롤 / 킥아웃 / 기브앤고는 둘의 능력치와 포지션으로 정한다. 둘이 같이 코트에 있으면 서로 더 찾고 (패스 가치 +), 콤비로 넣은 슛은 조금 더 잘 들어가고 '콤비!' 컷인. 픽앤롤 콤비면 짝이 스크린을 건다. 감독도 콤비 짝을 나와 같이 더 쓴다 (짝이 벤치여도 경기당 1~2번). 졸업·이적으로 떨어지면 해체. 카드와 팀 탭에 🤝
- 연애 (R4): 설정에서 끌 수 있다 (기본 켜짐). 이벤트 여섯 개 (만남 → 데이트·응원·다툼 → 고백 → 프로 25살 넘어 청혼). 호감도가 0이 되면 헤어진다. 사귀는 동안 컨디션이 잘 안 떨어진다. 결혼하면 은퇴식과 2세 화면에 배우자 이름
- 3x3 길거리 대회 (L8): 비시즌 여름 (고교·대학 7~8월, 프로 시즌 전) 초대장 이벤트. 나 + 가장 친한 팀원 둘, 8팀 토너먼트, 21점 먼저 또는 10분. 한 점씩 쌓이는 점수판으로 빠르게 진행. 우승하면 상금 (고교 50만 / 대학 100만 / 프로 1,000만)·인기·트로피 (학교 대회 우승으로는 안 센다)
- 전지훈련 (L8): 고교·대학은 1월, 프로는 프리시즌 전 한 번. 산악 (피지컬 +16, 지구력·근력·점프력), 해외 스킬캠프 (기술 +20, 필요한 분야), 은사 합숙 (은사를 만났으면, 정신 +14 기술 +6). 다녀오면 피로 +18
- 훈련 미니게임 (T4): 개인 훈련 슈팅 (타이밍 막대 세 번), 개인 훈련 돌파 (방향 일곱 개 5초), 웨이트 (5초 연타). 점수에 따라 포인트·경험치 ×0.8~1.3, 건너뛰거나 Esc면 ×1.0. 생활 탭 설정에서 끈다
- 포지션 전향: 다른 포지션 종합이 2.5 넘게 높으면 감독이 제안 (반년에 한 번까지). 바꾸면 감독 신뢰 +3, 그 포지션 분야 경험치. 거절하면 신뢰 -1
- 업적 4개 더 (환상의 짝꿍, 길거리의 왕, 새 자리, 평생의 짝). 개발자 패널 이벤트 탭에 M13 강제 버튼
- 자동 진행은 3x3 출전, 전지훈련 (잘 키우기는 스킬캠프부터), 전향 수락을 알아서 한다
- 세이브 v6 (v1~v5 자동 변환)
- 밸런스 확인 (`tools/balance.ts simple 1 6`, M12와 같은 시드): M13 기능(전지훈련·3x3·연애 컨디션·전향)으로 늘어난 건 프로 1년차 종합 +1 정도. 잘 키우기와 단순 플레이의 종합 차이는 프로 3년차 약 10 그대로
- 남은 점: 종합 62~65 선수도 득점이 몰리면 MVP를 받는다 (M11 때도 시드 2에서 나왔다). 단순 플레이도 시드에 따라 프로 2년차 MVP. 상 기준이나 리그 세기를 손볼지 정해야 한다

## M14. 인게임 에디터 ✅

- 개발자 패널 '에디터' 탭: 묶음 (나, 우리 팀, 라이벌, 리그 팀별, 국내·해외 리그, 고교·대학 상대 학교) 고르기, 이름 찾기 (전체), 선수마다 ✏️
- 팀 탭 선수 옆 ✏️ (패널을 연 동안만 보인다), 리그 탭 선수 옆 ✏️
- 편집 창: 능력치 39개 (슬라이더 + 숫자 + 등급), 전부 ±5 / 전부 N, 포지션별 종합이 바로 바뀌어 보임, 특수능력 ★0~3, 이름·등번호·포지션·나이·키·윙스팬·체중, 겉모습 (도트 미리보기), 열린 덩크
- 내 선수만: 성격 (개수 제한 없음), 잠재력, 성장 타입, 최종 키, 연애 상대 (이름·호감도·관계, 만들기·헤어지기)
- 팀원만: 나와의 친밀도, 콤비 (없음 / 앨리웁 / 픽앤롤 / 킥아웃 / 기브앤고)
- 바꾸면 바로 반영·저장. '처음 값으로'는 창을 연 때로 되돌린다. Esc나 바깥을 누르면 닫힌다
- 상대 학교 선수는 해마다 새로 만들어져서 고친 사본을 세이브에 따로 두고 그해 경기에 쓴다 (새해에 지운다)
- 🔧: 내 선수는 무엇이든, 다른 선수는 이름·등번호·겉모습만 고치면 안 남는다

## M15. 상 기준과 리그 세기 ✅

- MVP·베스트 5는 기자단 투표처럼 **기록 + 팀 성적 + 평판(종합 능력치)**. 기록 점수는 득점에 리바운드·어시스트·스틸·블록까지
- 득점왕·리바운드왕·어시스트왕·수비상은 기록 그대로 (3점만 몰아 키워도 득점왕은 받는다)
- 리그 득점 분배: 에이스가 더 넣는다 (리그 득점 1위 25~32점). 리그를 만들 때 팀마다 에이스 능력치 +3
- 결과 ([보고서](m15-balance-report.txt)): 단순 플레이는 프로 4시즌에 MVP 0, 올스타 3번 (세 시드). 잘 키우기는 3년차부터 MVP, 베스트 5 해마다
- `tools/balance.ts`에 `AW=1` (해마다 수상자와 그 종합)
