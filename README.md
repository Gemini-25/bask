# bask

2D 도트(카이로소프트 느낌) 농구 선수 육성 시뮬레이션. 개인 프로젝트.

- 나만의 선수 한 명을 고교부터 키우는 커리어
- 기술 / 정신 / 피지컬 능력치 39개와 특수능력
- 10명이 스스로 판단하며 움직이는 경기를 실시간으로 관람

## 플레이

`play/bask.html` 파일 하나를 받아서 더블클릭하면 브라우저에서 바로 열린다. 인터넷 연결 없이도 된다.

프로 쪽만 빨리 보고 싶으면 `play/sample-pre-draft-save.json`을 타이틀의 '파일 불러오기'로 넣으면 고3 마지막 주부터 시작한다 (다음 주가 드래프트).

지금 버전은 **M13 남은 기획** (M8 프로 커리어 끝까지 + M9 개발자 패널 + M10 연출 + M11 밸런스 + M12 대학·성격 +): 선수를 만들어 고교 3년 동안 키우고, 드래프트로 프로 팀에 들어가 상을 받고, 올스타·국가대표·해외 리그를 거쳐 은퇴하면 2세로 이어 간다.

- 선수 만들기: 출신 배경 7가지(천재 포함) + 자유 포인트 배분, 키·체형, 겉모습, 학교
- 마을 맵에서 매주 행동 하나 (팀 훈련, 개인 훈련, 은사 특훈, 웨이트, 영상 분석, 길거리 3x3, 친구와 놀기, 휴식, 재활) → 포인트 → 능력치 투자
- 피로가 쌓이면 다치기 쉽고 컨디션이 떨어진다
- 공식 대회 4개 (춘계 연맹전, 협회장기, 전국체전, 왕중왕전) + 연습경기를 3/4 쿼터뷰 경기장에서 관람 → 성장 결과
- 감독 신뢰도가 높아야 공식전에서 많이 뛴다. 팀원 친밀도, 라이벌, 은사, 이벤트 20가지
- 특수능력 12가지 (★1~3 진화, 나쁜 버릇 포함), 덩크 6종 해금
- 동작 30가지, 감정 아이콘, 교체 입장, 경기 끝 세리머니, 경기장 3단계 (학교 체육관 / 대회장 / 결승 무대)
- 행동마다 다른 훈련 장면, 효과음과 칩튠 음악 (머리글에서 켜고 끄기)
- 해가 바뀌면 진급·졸업. 고3이 끝나면 드래프트 → 신인 계약 → 프로 리그 (27경기 + 플레이오프), 해마다 나이·은퇴·신인이 바뀌는 리그
- 연봉으로 장비·집 꾸미기, 개인 트레이너·광고 촬영, 인기·SNS 반응·인터뷰, 재계약과 FA 이적
- 시즌 시상식 (MVP, 신인왕, 득점·리바운드·어시스트왕, 수비상, 베스트 5), 트로피와 시즌별 기록
- 올스타 위크엔드: 올스타전, 3점 콘테스트, 덩크 콘테스트. 비시즌엔 국가대표 아시아컵
- 해외 리그 진출 (쿼터 12분, 6반칙 퇴장, 더 센 가상 리그)과 국내 복귀
- 은퇴식, 명예의 전당, 영구결번, 2세 계승, 업적 31개 (타이틀 화면에 남는다)
- 고3이 끝나면 고졸 드래프트 또는 대학 진학 (대학 10곳, 대학 대회 4개, 해마다 얼리 엔트리)
- 성격 8가지 (만들 때 하나 + 이벤트로 하나), 고교·대학 아르바이트
- 친한 팀원과 콤비 기술 (앨리웁·픽앤롤·킥아웃·기브앤고), 감독의 포지션 전향 제안
- 비시즌 3x3 길거리 대회 (빠르게 진행)와 전지훈련 세 가지
- 연애 이벤트 (설정에서 끄기), 훈련 미니게임 세 가지 (슈팅 타이밍·드리블 방향키·웨이트 연타, 끄기·건너뛰기 가능)
- 키운 만큼 차이 난다: 대충 키우면 주전·올스타, 은사·트레이너·피로 관리·장비까지 챙기면 MVP
- 드리블 기술 5가지와 덩크 10가지, 쳐낸 공·블록이 날아가는 궤적, 응원단과 천장 배너, BGM 6곡, 우승·시상·드래프트 무대 장면, 시즌 요약 카드
- 저장은 브라우저 슬롯 3개 + 세이브 파일 내보내기·불러오기 (예전 세이브 자동 변환)
- 타이틀의 '프로 리그 경기 관람 (데모)'는 프로 팀끼리 경기

개발자 패널: 백틱(`) 키나 머리글 BASK 로고를 5번 누르면 열린다. 능력치 고치기, 날짜 점프, 이벤트 강제 발동, 슛 확률 표시, 100배속, 스냅샷. 값을 바꾼 커리어엔 🔧 표시가 남는다.

경기 화면 조작:

- Space 재생/정지 · 1~5 배속 (1x, 2x, 4x, 8x, 16x) · Q 쿼터 넘기기 · H 하이라이트 · N 새 경기
- 보는 방법: 전체 / 고른 선수만 (그 선수가 코트에 있을 때만) / 하이라이트
- 박스스코어나 선수 탭에서 선수를 누르면 코트에 노란 화살표가 뜨고 능력치 39개를 볼 수 있다
- 샷차트 탭: 슛 위치와 구역별 성공률, 흐름 탭: 승리 확률 그래프

## 개발

```sh
npm install
npm run dev        # 개발 서버
npm test           # 단위·밸런스 테스트
npm run build      # dist/index.html 하나로 빌드
npm run report     # 100경기 돌려서 평균 통계를 실제 리그와 비교
```

디버그 도구 (`tools/`):

- `npx tsx tools/ascii.ts [시드] [시작초] [길이초] [간격초]`: 경기를 글자 코트로 찍는다
- `npx tsx tools/think.ts [시드] [시작초] [끝초]`: 공 가진 선수가 어떤 선택지를 몇 점으로 봤는지
- `npx tsx tools/shots.ts`: 슛 종류별 수비 견제 분포
- `node tools/frames.mjs [출력.png] [시드] [시작초] [장 수] [간격초]`: 빌드된 화면을 연속 캡처
- `npx tsx tools/wp.ts [경기 수]`: 승리 확률 계수 맞추기와 보정 확인
- `npx tsx tools/career.ts [주 수] [배경] [포지션] [시드]`: 커리어 자동 플레이 (성장 곡선, 출전 시간, 부상). `V=1` 경기마다, `T=1` 대회 성적, `E=1` 이벤트, `SCHOOL=TAML` 학교 바꾸기
- `node tools/career-ui.mjs <주소> <폴더>`: 타이틀 → 만들기 → 4주 → 연습경기 → 결과 → 저장 내보내기·불러오기 화면 캡처
- `node tools/charts.mjs <주소> <폴더> [시드]`: 샷차트·흐름·하이라이트 화면 캡처
- `sprites.html`, `scenes.html` (개발 서버에서 열기): 도트 캐릭터 동작 × 방향 시트, 훈련 장면 전부
- `node tools/scene.mjs <폴더> [시드]`: 경기장 단계·교체 입장·경기 끝 연출 캡처
- `npx tsx tools/full.ts [시드] [햇수] [abroad]`: 고교 3년 → 드래프트 → 프로 자동 플레이 (시상, 올스타, 국가대표, 은퇴까지). `abroad`면 해외 제안을 받는다
- `npx tsx tools/make-save.ts <주 수> <출력.json> [시드] [abroad]`: 그 주까지 자동으로 진행한 세이브 파일 (화면 확인용, 타이틀에서 '파일 불러오기')
- `node tools/career-ui3.mjs <주소> <폴더> <세이브.json>`: 드래프트·프로 화면 캡처
- `npx tsx tools/balance.ts <simple|good> <시드> [햇수] [spread]`: 자동 플레이 두 가지로 해마다 종합·득점·인기·수상 (키운 만큼 차이 나나)
- `node tools/cheer-ui.mjs <주소> <폴더> <프로 세이브.json>`, `node tools/m10-ui.mjs <주소> <폴더> <올스타 직전 세이브> <드래프트 직전 세이브>`: 응원단·덩크 콘테스트·시즌 카드·시상식·드래프트 무대 캡처
- `node tools/m12-ui.mjs <주소> <폴더> <고3 마지막 주 세이브>`: 진로 선택 → 대학 입학 → 대학 일정 → 성격 칸 캡처
- `node tools/dev-ui.mjs <주소> <폴더> <세이브.json>`: 개발자 패널 탭별 화면 캡처
- `node tools/m13-ui.mjs <주소> <폴더> <프로 세이브.json>`: 3x3·전지훈련·전향 제안·콤비·연애 표시·미니게임 세 가지 캡처, `node tools/combo-ui.mjs <주소> <폴더> <프로 세이브.json>`: 콤비 둘로 경기 관람, `npx tsx tools/combo-check.ts <세이브.json> [경기 수]`: 콤비가 경기당 몇 번 나오나 (`V=1` 출전 시간)
- `node tools/career-ui4.mjs <주소> <폴더> <세이브.json> [이름표]`: 올스타 위크엔드·국가대표·해외 경기 화면 캡처. `RETIRE=1`이면 은퇴식 → 2세 → 타이틀, `WATCH=1`이면 경기 화면도

## 구조

- `src/sim/`: 경기 엔진. 화면 없이 돌아가고 0.1초 프레임 기록과 이벤트를 만든다
- `src/career/`: 육성 규칙 (배경, 학교, 주간 행동, 피로·부상·컨디션, 능력치 투자, 고교 시즌·대회, 사람들, 이벤트, 특수능력, 드래프트, 프로 리그, 시상, 올스타·국가대표, 해외 리그, 은퇴·명예의 전당·업적, 돈, 인기, 저장). 화면 없이 테스트한다
- `src/app/`: 경기 밖 화면 (타이틀, 선수 만들기, 홈, 결과, 모달)
- `src/data/`: 능력치, 선수 생성, 가상 리그 10팀
- `src/view/`: Phaser 경기장 화면(`arena.ts` 경기장, `character.ts` 도트 캐릭터, `CourtScene.ts` 연출)과 HTML UI·차트. 엔진이 만든 기록을 재생만 한다
