# bask

2D 도트(카이로소프트 느낌) 농구 선수 육성 시뮬레이션. 개인 프로젝트.

- 나만의 선수 한 명을 고교부터 키우는 커리어
- 기술 / 정신 / 피지컬 능력치 39개와 특수능력
- 10명이 스스로 판단하며 움직이는 경기를 실시간으로 관람

## 플레이

`play/bask.html` 파일 하나를 받아서 더블클릭하면 브라우저에서 바로 열린다. 인터넷 연결 없이도 된다.

지금 버전은 **M7 프로 데뷔**: 선수를 만들어 고교 3년 동안 키우고, 드래프트로 프로 팀에 들어가 시즌을 치른다.

- 선수 만들기: 출신 배경 7가지(천재 포함) + 자유 포인트 배분, 키·체형, 겉모습, 학교
- 마을 맵에서 매주 행동 하나 (팀 훈련, 개인 훈련, 은사 특훈, 웨이트, 영상 분석, 길거리 3x3, 친구와 놀기, 휴식, 재활) → 포인트 → 능력치 투자
- 피로가 쌓이면 다치기 쉽고 컨디션이 떨어진다
- 공식 대회 4개 (춘계 연맹전, 협회장기, 전국체전, 왕중왕전) + 연습경기를 3/4 쿼터뷰 경기장에서 관람 → 성장 결과
- 감독 신뢰도가 높아야 공식전에서 많이 뛴다. 팀원 친밀도, 라이벌, 은사, 이벤트 20가지
- 특수능력 12가지 (★1~3 진화, 나쁜 버릇 포함), 덩크 6종 해금
- 동작 30가지, 감정 아이콘, 교체 입장, 경기 끝 세리머니, 경기장 3단계 (학교 체육관 / 대회장 / 결승 무대)
- 행동마다 다른 훈련 장면, 효과음과 칩튠 음악 (머리글에서 켜고 끄기)
- 해가 바뀌면 진급·졸업. 고3이 끝나면 드래프트 → 신인 계약 → 프로 리그 (27경기 + 플레이오프), 해마다 나이·은퇴·신인이 바뀌는 리그
- 연봉으로 장비·집 꾸미기, 개인 트레이너·광고 촬영, 인기·SNS 반응·인터뷰, 재계약과 FA 이적
- 저장은 브라우저 슬롯 3개 + 세이브 파일 내보내기·불러오기 (예전 세이브 자동 변환)
- 타이틀의 '프로 리그 경기 관람 (데모)'는 프로 팀끼리 경기

경기 화면 조작:

- Space 재생/정지 · 1~5 배속 (1x, 2x, 4x, 8x, 16x) · Q 쿼터 넘기기 · H 하이라이트 · N 새 경기
- 보는 방법: 전체 / 고른 선수만 (그 선수가 코트에 있을 때만) / 하이라이트
- 박스스코어나 선수 탭에서 선수를 누르면 코트에 노란 화살표가 뜨고 능력치 39개를 볼 수 있다
- 샷차트 탭: 슛 위치와 구역별 성공률, 흐름 탭: 승리 확률 그래프

## 개발

```sh
npm install
npm run dev        # 개발 서버
npm test           # 단위·밸런스 테스트
npm run build      # dist/index.html 하나로 빌드
npm run report     # 100경기 돌려서 평균 통계를 실제 리그와 비교
```

디버그 도구 (`tools/`):

- `npx tsx tools/ascii.ts [시드] [시작초] [길이초] [간격초]`: 경기를 글자 코트로 찍는다
- `npx tsx tools/think.ts [시드] [시작초] [끝초]`: 공 가진 선수가 어떤 선택지를 몇 점으로 봤는지
- `npx tsx tools/shots.ts`: 슛 종류별 수비 견제 분포
- `node tools/frames.mjs [출력.png] [시드] [시작초] [장 수] [간격초]`: 빌드된 화면을 연속 캡처
- `npx tsx tools/wp.ts [경기 수]`: 승리 확률 계수 맞추기와 보정 확인
- `npx tsx tools/career.ts [주 수] [배경] [포지션] [시드]`: 커리어 자동 플레이 (성장 곡선, 출전 시간, 부상). `V=1` 경기마다, `T=1` 대회 성적, `E=1` 이벤트, `SCHOOL=TAML` 학교 바꾸기
- `node tools/career-ui.mjs <주소> <폴더>`: 타이틀 → 만들기 → 4주 → 연습경기 → 결과 → 저장 내보내기·불러오기 화면 캡처
- `node tools/charts.mjs <주소> <폴더> [시드]`: 샷차트·흐름·하이라이트 화면 캡처
- `sprites.html`, `scenes.html` (개발 서버에서 열기): 도트 캐릭터 동작 × 방향 시트, 훈련 장면 전부
- `node tools/scene.mjs <폴더> [시드]`: 경기장 단계·교체 입장·경기 끝 연출 캡처
- `npx tsx tools/full.ts [시드]`: 고교 3년 → 드래프트 → 프로 2시즌 자동 플레이
- `npx tsx tools/make-save.ts <주 수> <출력.json> [시드]`: 그 주까지 자동으로 진행한 세이브 파일 (화면 확인용, 타이틀에서 '파일 불러오기')
- `node tools/career-ui3.mjs <주소> <폴더> <세이브.json>`: 드래프트·프로 화면 캡처

## 구조

- `src/sim/`: 경기 엔진. 화면 없이 돌아가고 0.1초 프레임 기록과 이벤트를 만든다
- `src/career/`: 육성 규칙 (배경, 학교, 주간 행동, 피로·부상·컨디션, 능력치 투자, 고교 시즌·대회, 사람들, 이벤트, 특수능력, 드래프트, 프로 리그, 돈, 인기, 저장). 화면 없이 테스트한다
- `src/app/`: 경기 밖 화면 (타이틀, 선수 만들기, 홈, 결과, 모달)
- `src/data/`: 능력치, 선수 생성, 가상 리그 10팀
- `src/view/`: Phaser 경기장 화면(`arena.ts` 경기장, `character.ts` 도트 캐릭터, `CourtScene.ts` 연출)과 HTML UI·차트. 엔진이 만든 기록을 재생만 한다
